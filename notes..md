
## Download Slides as PDF

Reveal presentations can be exported to PDF via a special print stylesheet (works in Google Chrome, Chromium, and Firefox).

1. Open any slide deck from the modules above.
2. Toggle into **Print View** by pressing `E` (or using the Navigation Menu → **Tools** → **Print to PDF**).
3. Open the in-browser print dialog:
   - **Windows / Linux:** `Ctrl+P`
   - **macOS:** `Cmd+P`
4. Change the **Destination** setting to **Save as PDF**.
5. Change the **Layout** to **Landscape**.
6. Change the **Margins** to **None**.
7. Enable the **Background graphics** option.
8. Click **Save**.

If you entered print mode in the same window, press `E` again to leave Print View (or use the browser back button to return to the last slide you were on).

See the [Quarto Print to PDF docs](https://quarto.org/docs/presentations/revealjs/presenting.html#print-to-pdf) for more detail.

## Presenting Slides

See [Quarto docs for Presenting Slides](https://quarto.org/docs/presentations/revealjs/presenting.html).

| Action | Trigger |
| -------------- | --------- |
| Next slide | `→` or `SPACE` or `N` |
| Previous slide | `←` or `P` |
| [Speaker view](https://quarto.org/docs/presentations/revealjs/presenting.html#speaker-view) | `S` |
| [Outline](https://quarto.org/docs/presentations/revealjs/presenting.html#navigation-menu) | `M` |
| [Overview mode](https://quarto.org/docs/presentations/revealjs/presenting.html#overview-mode) | `O` |
| [Jump to slide \#](https://quarto.org/docs/presentations/revealjs/presenting.html#jump-to-slide) | `G` |
| [Slide zoom](https://quarto.org/docs/presentations/revealjs/presenting.html#slide-zoom) | `Ctrl + Click` |
| [Chalkboard](https://quarto.org/docs/presentations/revealjs/presenting.html#chalkboard) | `C` canvas, `B` board |
