## About
An introduction to moving a machine learning model beyond the notebook.

Learners compare common deployment patterns and cloud options, evaluate key cost and performance considerations, and use MLflow to track, package, serve, and test an existing `scikit-learn` pipeline locally.

## Learning Objectives

*You will be able to:*

- Explain what MLOps is and its role in the data science lifecycle.
- Choose an appropriate deployment approach.
- Apply core MLOps best practices.
- Deploy and test a model locally with MLflow.

## Prerequisites
**Before this lesson, you should already be able to:**
- Run and troubleshoot Jupyter notebooks (install packages, restart kernels, read error output)
- Run virtual environments
- Build `scikit-learn` pipelines: build a Pipeline with preprocessing + estimator steps (taught in a separate Gridsearch and Pipelines lesson)
- Run classification fundamentals: fit a `LogisticRegression` model and interpret accuracy / ROC AUC
- Have basic command line / HTTP familiarity: comfortable with the idea of a URL, a port, and a request/response (no coding required, just conceptual — this notebook introduces POST requests, but doesn't teach HTTP from scratch)
- Understand the data science lifecycle: understanding that "build a good model" isn't the same as "the project is done"
